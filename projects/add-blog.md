Blog hosting platform designed to work with CloudFlare hosted domains. Uses D1 database(s), a worker and zero trust access to power one or more blogs. Each blog gets an associated admin interface. Media, tags and RSS support.

Worker also supprts MCP access so, for example, a Connector to the blog can be added to Claude to enable a set of tools to manage the blog and content.
