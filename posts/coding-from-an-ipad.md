---
title: Coding from an iPad
date: 2026-08-30
description: After months of running my coding workflow through a Windows VM just to keep my iPad light on the road, I’ve switched to native Claude Code sessions on iOS. A look at what changed, what’s still missing (testing, mainly), and why the sandboxed setup might actually be safer than what it replaced.
---

I should start this post by saying it is unclear to me if Claude on iOS has had this ability for ages and I’ve just been slow to notice, or if this is a recent enhancement, however, being able to work directly with Claude on my repos from my iPad is improving my workflow.

I’ll back up a bit, as I guess most people are not doing most of their vibe coding from an iPad, but given when I have spare time and my desire to limit the weight I carry around while travelling, the iPad is my preferred device for most personal computing tasks.

Up until now, I’ve been using a virtual Windows machine as the central point of my vibe coding. This device has been running GitHub desktop, VS Code with the Claude Code extension. That setup has worked pretty well for me, the Windows app on iPad allowed me to connect into the Windows machine to launch or monitor sessions, and commit and push code at the same time as giving Claude some tools to test the code.

But it is not as convenient as doing everything natively.

Using Claude Code on the iPad is not going to replace everything, testing in particular will be challenging. But that limitation is also part of the benefits; an element of what I liked about using a virtual Windows machine was the fact that I was doing nothing else with that machine, so if Claude misinterpreted my instructions not much damage could be caused. I think that is going to be even better with the iPad app, as the coding sessions occur remotely in a dedicated container.

Let’s see how this develops, at the moment I’m happy with this new approach. Who knows maybe I’ll get to move on to using Claude Cowork which was always in my plans, but yet to really happen.
